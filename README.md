# PIEAN ANOMALY

เกมสยองขวัญบนเว็บแนวสังเกตสิ่งผิดปกติผ่านกล้องวงจรปิด
**"สังเกตสิ่งผิดปกติ... ก่อนที่มันจะสังเกตคุณ"**

ทำด้วย HTML / CSS / JavaScript ล้วน ไม่ต้องติดตั้ง library และไม่ต้อง build

## วิธีเล่น

คุณเป็นยามกะดึกที่เฝ้าโรงเรียนร้างผ่านกล้องวงจรปิด 6 จุด:
ทางเดิน, บันได, โรงอาหาร, ห้องคอม, ห้องน้ำ, ห้องประชุม

1. เกมเริ่มด้วยการนับถอยหลังเตรียมตัว 30 วินาที
2. จากนั้นเล่นหลัก 3 นาที ทุก 15 วินาทีจะมีห้องที่เกิดสิ่งผิดปกติเพิ่ม
3. สลับกล้องเพื่อหาห้องที่ผิดปกติ แล้วกด **REPORT ANOMALY** ขณะดูห้องนั้น
4. ระบบใช้เวลาตรวจสอบประมาณ 3 วินาที

### กติกา
| รายการ | ค่า |
|---|---|
| ค่าสติ (Sanity) เริ่มต้น | 100% |
| ค่าสติลดลง | 0.5% ต่อวินาที ต่อห้องที่มีสิ่งผิดปกติ |
| ค่าสติฟื้น | 0.2% ต่อวินาที เมื่อไม่มีสิ่งผิดปกติ |
| รายงานถูก | ค่าสติ +10% |
| รายงานผิดได้ | ไม่เกิน 5 ครั้ง |
| ชนะ | อยู่ครบ 3 นาที และค่าสติ ≥ 20% |
| แพ้ | ค่าสติเหลือ 0%, รายงานผิดครบ 5 ครั้ง หรือครบเวลาแต่ค่าสติ < 20% |

ถ้ามีสิ่งผิดปกติพร้อมกันเกิน 3 ห้อง จะมีแถบเตือนขึ้น

## วิธีรันเกม

เปิดไฟล์ `PIEAN ANOMALY/index.html` ในเบราว์เซอร์ได้เลย หรือรันผ่านเซิร์ฟเวอร์ในเครื่อง:

```bash
cd "PIEAN ANOMALY"
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

## โครงสร้างโปรเจกต์

```
PIEAN ANOMALY/
├── index.html    # หน้าจอทั้งหมด (เมนู, เลือกด่าน, เนื้อเรื่อง, โหลด, เล่น, จบเกม)
├── style.css     # สไตล์และ responsive layout
├── script.js     # ตรรกะเกม (ห้อง, ตัวจับเวลา, ค่าสติ, การรายงาน)
├── images/       # ภาพกล้องของโรงเรียน (ภาพปกติ 1 + ภาพผิดปกติ 3 ต่อห้อง)
└── hospital/     # ภาพสำหรับด่านโรงพยาบาล (ยังไม่เปิดใช้)
```

## สถานะ

- [x] ด่านโรงเรียน
- [x] รองรับมือถือ แท็บเล็ต และเดสก์ท็อป
- [ ] ด่านโรงพยาบาลรกร้าง (ล็อกอยู่ มีภาพเตรียมไว้แล้ว)

## เพิ่มห้องหรือภาพผิดปกติ

แก้ `roomsData` ที่ต้น `script.js` ใส่ path ของภาพปกติและภาพผิดปกติ
แล้วเพิ่มปุ่มกล้องใน `index.html`
